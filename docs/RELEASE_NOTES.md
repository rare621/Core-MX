## Gear folder repair, Apply controls, and improved downloads and friends

Close MX Bikes and MX Bikes Manager, then install **MX-Bikes-Manager-Setup-1.0.7-x64.exe** on both PCs.

**Online server update required:** stop the server, replace **mxbm-server.js** in its existing folder with the script from **mxbm-online-service.zip**, then restart **start-server.cmd**. Keep **mxbm-data.json** and **mxbm-files**. The health page should report `"version":4`. Accounts and shared files are preserved; the bundled public service address remains **http://67.84.130.214:60000**.

- **Correct gear folders:** helmets, boots, protection and their paints now use the shared folders directly under `mods/rider/`. Rider bodies, kit paints and glove paints use `mods/rider/riders/<body>/`. Corrected installs, catalog discovery, previews, post-install equip choices and friend sync. With the game closed, the updated app repairs the previous manager's misplaced accessory folders on startup. Different existing files are kept, and only verified identical extra copies go to the Recycle Bin. Install records follow the moved files.
- **Settings → Fix & clean:** maintenance has moved out of Game into its own Settings tab. Removed the incorrect cleanup rule that classified valid shared accessory folders as obsolete. Folder repair is also available here.
- **Preview, then Apply:** Outfit and Bike choices no longer write the game profile on every selection. Apply saves the selected profile, bike, livery, gear and tyres, activates that profile, and verifies the saved selections. Revert discards the current preview. Apply is blocked while the game is running so its exit cannot overwrite the changes; the preview remains available to apply after closing it. Added Rider Refresh, game-profile change detection, and profile deletion with confirmation.
- **Bike and rider previews:** added a tyre selector and selected tyre-model rendering, None protection, real protection-model filtering, and goggles thumbnails using the chosen helmet paint. Bike livery selection continues to use download-page images.
- **Get Mods:** renamed Free mods to **MXB Mods** and added **Addons**, using filtered live listings from the same site with relevant categories. Browsing does not download mod archives. Fixed a stale loading state during searches and added a timeout with retry. Bike liveries no longer receive a model-dependency warning; uncertain destinations still ask which bike to use.
- **Installation:** listing pages show download and install progress, including browser steps and review. Closing a download browser or cancelling before the install commits resets the Install button and cleans app staging. Partial writes roll back and overwritten originals are restored. The destination dialog is simpler, with searchable brand/cc bike choices and expandable file details.
- **After installing:** choose **Equip now**, **Customize first**, or **Skip**. Customize uses the paint preview grid; selecting a paint previews it until Equip selected is pressed. Shared accessories preserve the current rider body.
- **Downloads:** Recent installs shows the last ten installs, their source pages and current paths. Change install location reopens the usual destination choices, prefilled, for moving installed content without downloading it again. Completed history keeps ten entries; Clear all removes completed history without deleting installed mods.
- **Graphics:** fixed managed-package uninstall and added one-active-package switching. Multiple packages can remain installed; enabling one disables the previous package. Disabling or uninstalling restores backed-up game files.
- **Friends:** moved the searchable five-row friend list into the bottom-left Steam account panel, with Show all and friend details. Added self-friending for testing. Online tabs are Servers, Ranked, Host, Sync; Sync contains sharing settings. Removing synced files requires confirmation. Progress is an overlay so it does not shift the page.
- **Equipped sync and presence:** sync checks equipped gear, paints, bike livery and tyres each minute, skips identical installed content, and leaves the local outfit selected. Fixed the presence plugin returning the disabled startup value; session events can now report server/track presence. Installed plugin updates are handled by the app when MX Bikes is closed, with an Update plugin action for a pending update.
- **Servers:** preserved the global participating-user list. Added population and network-ping filters. Automatic list refresh is every five minutes while Online is open; manual Refresh forces a refresh. Full/empty information depends on the data reported, and full capacity stays unknown when no limit is supplied.

Validation: 77 automated checks passed, including folder repair with conflicting and identical files, separate body/accessory routing, graphics switching and rollback, cancellation recovery, equipped tyre packages, the actual Windows plugin ABI, and two isolated service clients. Hidden Electron checks exercised progress, cancellation, Addons, friends, equip customization, Apply drafts and the Settings maintenance tab. Separate app-process checks verified saved profile/bike/gear/tyre selections after restart. The repaired local helmet preview was also loaded successfully. A live join between two real game clients and live in-game tyre appearance have not been verified.
