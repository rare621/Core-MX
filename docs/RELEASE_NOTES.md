Install **MX-Bikes-Manager-Setup-1.0.0-x64.exe** on 64-bit Windows. Node.js and npm are not needed to run the installed app. MX Bikes is installed separately through Steam.

- Manage bikes, tracks, rider gear, and individual bike paints.
- Browse mods and signed-in purchases from supported stores.
- Preview installed bikes and outfits in 3D with selected paints.
- Filter bikes by brand, engine size, and class; filter rider gear by brand.
- Create multiple game profiles and gear setups.
- Configure rides, game settings, and multiplayer hosting.
- Install archives with review controls, content verification, and temporary-file cleanup.

The setup adds Start menu and desktop shortcuts, registers join links, and includes an uninstaller. Uninstalling keeps manager settings and game mods.

This build is unsigned, so Windows may show an unknown-publisher warning. Check the download against SHA256SUMS.txt. The package contains the manager and its presence plugin; it does not contain MX Bikes, mod models/paints, or the developer's accounts and settings.

Live presence, friends, and paint sharing require a separately hosted online service. The public build has no service address configured by default. Store browsing, local mod management, previews, and profiles work independently.
