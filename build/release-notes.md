CoreMX 1.0.27

- My Mods → Bikes now shows each bike's saved 3D render on its card, even when an older assigned picture exists.
- Opening a bike now displays that same saved image immediately in the detail preview instead of starting another interactive 3D render.
- A newly generated image updates an already open bike preview. Bikes that cannot be rendered still use their existing pictures.

For Google Drive updates, upload latest.yml and MX-Bikes-Manager-Setup-1.0.27-x64.exe together to the shared update folder. CoreMX-Setup-1.0.27-x64.exe is the same installer for direct downloads.
