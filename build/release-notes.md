CoreMX 1.0.28

- Updates now come from public Core-MX GitHub releases. The release contains one CoreMX setup EXE, its update manifest, checksums, and the online service ZIP.
- Added an Admin settings tab for the registered CoreMX owner. It shows the account count and publishes announcements that appear once in the app and remain in Notifications. Deploy this release's online service ZIP to enable it.
- Friend sharing now uses a readable dark picker. Notifications separate announcements and friend shares, show five at a time, and let recipients open or delete each item. Opening a shared mod clears the share.
- Added the four community fixes: MXB Hub Blender downloads appear under Other / Tools, mod pages show download counts and separate Description and Installation tabs, and Get Mods Popular today and Popular all time use the correct listing data.

Existing 1.0.27 installations still check Google Drive. To move them to GitHub updates automatically, upload this release's latest.yml and CoreMX-Setup-1.0.28-x64.exe together to the shared Google Drive update folder once. After updating, they use GitHub. The server ZIP must be deployed separately for announcements.
