CoreMX 1.0.37

- The CoreMX game plugin now handles server-address discovery without the bundled FrostMod plugin.
- Live rider looks can show shared bike liveries, rider paints, gear models, and first-person models in game.
- An in-game overlay lets you preview and choose your own gear and paints. Configure its F1–F11 shortcut in Settings → Plugins; the default is F8. The picker is locked during races.
- Queued gear checks the matching model before applying a paint, and unreadable files are no longer counted as paid mods.
- Friends and Online views handle refreshes and game-hosted server status more reliably.

The online service included with this release is version 14. When updating an existing server, replace only the service source files and keep your account data, admin key, and shared-file folder.
