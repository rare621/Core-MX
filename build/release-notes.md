CoreMX 1.0.52

- Shop downloads now hide the shop window once the file starts, show a Downloading window with progress, and open the install review when the download finishes.
- Gear installed for another rider through automatic sync or the Missing gear flow is no longer offered in your own Rider customization choices.

Includes **CoreMX-server-v27.zip** for completeness. The server code did not change, and the live service was already v27 when prepared, so **no server update is needed**. Users should update the app to 1.0.52 for these fixes.
