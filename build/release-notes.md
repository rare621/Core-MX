CoreMX 1.0.29

- Get Mods now has one Mods catalog for regular mods and add-ons. Helmet, boot, and protection categories have model and paint filters, with helmet add-ons shown separately. Animation mods have their own category.
- Fixed intermittent empty Get Mods pages and Load more. Each filter keeps a bounded first-page cache and refreshes it in the background; later pages load from the source.
- Added an Animations tab in My Mods. Creator instructions determine whether .ANM files install in the MX Bikes game folder or mods folder. Install review shows the destination, backs up replaced game files, and does not silently choose among conflicting variants. Installed animations can be enabled, disabled, and removed.
- Added Enable and Disable controls for individual game plugins in My Mods.
- Friends refreshes when opened and updates the displayed list when the request finishes.

Close MX Bikes before changing plugins or rider animations. Existing CoreMX installations on 1.0.28 receive this update from the public Core-MX GitHub release.
